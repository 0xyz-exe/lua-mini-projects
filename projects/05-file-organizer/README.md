# Project 05: File Organizer

Organize files by extension into categorized folders.

## Features

- Scan directories
- Group by extension
- Dry-run preview
- Conflict handling
- Operation logging

## Usage

```bash
cd projects/05-file-organizer/src
lua main.lua
```

## Testing

```bash
cd projects/05-file-organizer/tests
lua test_organizer.lua
```
