# Project 04: Expense Tracker

Track income and expenses with categories and monthly summaries.

## Features

- Add income/expense records
- Category tracking
- Monthly summaries
- Balance calculation
- CSV export

## Usage

```bash
cd projects/04-expense-tracker/src
lua main.lua
```

## Testing

```bash
cd projects/04-expense-tracker/tests
lua test_expense.lua
```
