# Project 03: Task Manager CLI

Command-line task management with priorities and persistence.

## Features

- Create, edit, complete, delete tasks
- Priority levels (low/medium/high)
- Due dates
- Search and filter
- JSON persistence
- Status tracking

## Usage

```bash
cd projects/03-task-manager/src
lua main.lua
```

## Testing

```bash
cd projects/03-task-manager/tests
lua test_task.lua
```

## Dependencies

- Lua 5.3+
- No external dependencies (uses built-in JSON module)
