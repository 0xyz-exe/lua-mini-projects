# Project 07: Tic-Tac-Toe

Classic two-player terminal game.

## Features

- 2-player mode
- Win detection (rows, columns, diagonals)
- Draw detection
- Input validation
- Replay

## Usage

```bash
cd projects/07-tic-tac-toe/src
lua main.lua
```

## Testing

```bash
cd projects/07-tic-tac-toe/tests
lua test_game.lua
```
