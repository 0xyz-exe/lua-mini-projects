# Project 08: Snake Game (LÖVE)

Classic Snake game with LÖVE framework.

## Features

- Keyboard controls (WASD/Arrows)
- Food generation
- Collision detection
- Score tracking
- Pause/Restart

## Requirements

- LÖVE 11.x (https://love2d.org/)

## Usage

```bash
love projects/08-snake-love2d/src
```

## Controls

- Arrow keys or WASD: Move
- P: Pause
- R: Restart
- ESC: Quit

## Testing

```bash
cd projects/08-snake-love2d/tests
lua test_snake.lua
```

Note: Tests run game logic only (no graphics).
