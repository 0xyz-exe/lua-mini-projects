# Project 02: Number Guessing Game

Terminal-based number guessing game with difficulty levels.

## Features

- Random number generation
- Three difficulty levels (Easy: 1-50, Medium: 1-100, Hard: 1-500)
- Limited attempts based on difficulty
- Higher/lower hints
- Score tracking
- Replay functionality
- Persistent high scores

## Usage

```bash
cd projects/02-number-guessing/src
lua main.lua
```

## Testing

```bash
cd projects/02-number-guessing/tests
lua test_game.lua
```

## Dependencies

- Lua 5.3+
- No external dependencies
