# Project 09: 2D Platformer (LÖVE)

Simple platformer with physics and collectibles.

## Features

- Player movement and jumping
- Gravity and collision
- Platform levels
- Collectible coins
- Score tracking

## Requirements

- LÖVE 11.x (https://love2d.org/)

## Usage

```bash
love projects/09-platformer-love2d/src
```

## Controls

- A/D or Left/Right: Move
- Space: Jump
- P: Pause
- R: Restart
- ESC: Quit

## Testing

Game logic testing not implemented (requires LÖVE runtime).
