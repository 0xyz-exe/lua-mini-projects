# Project 06: Text & Log Analyzer

Analyze text files with statistics and search.

## Features

- Word/line/character counts
- Word frequency analysis
- Pattern search
- Log filtering

## Usage

```bash
cd projects/06-text-log-analyzer/src
lua main.lua input.txt
```

## Testing

```bash
cd projects/06-text-log-analyzer/tests
lua test_analyzer.lua
```
